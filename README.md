# 🎲 PartyForge

**PartyForge** — веб-приложение для игроков и мастеров настольных ролевых игр, совместимых с D&D 5E.

Проект объединяет создание персонажей, поиск игровых групп и управление кампаниями в одном приложении.

Основная цель проекта — упростить процесс от идеи персонажа до поиска подходящей партии.

---

## ✨ Возможности

### 🧙 Конструктор персонажей

Создание и хранение персонажей с основными характеристиками:

* имя;
* раса;
* класс;
* уровень;
* характеристики;
* навыки;
* описание персонажа.

Персонажи сохраняются в профиле пользователя и могут использоваться при подаче заявки в игровые группы.

---

### 📚 Справочник

Поиск и просмотр игровых сущностей:

* классов;
* рас;
* заклинаний;
* предметов;
* способностей;
* других элементов правил.

Поддерживаются поиск, фильтрация и получение подробной информации.

---

### ⚔️ Поиск группы

Мастера могут публиковать объявления о наборе игроков в кампанию.

В объявлении можно указать:

* название кампании;
* описание;
* формат игры;
* количество игроков;
* уровень персонажей;
* расписание;
* требования к участникам.

Игроки могут искать подходящие кампании и отправлять заявки вместе со своим персонажем.

---

### 👥 Управление участниками

Мастер кампании может:

* просматривать заявки;
* принимать игроков;
* отклонять заявки;
* управлять составом группы.

Игрок может отслеживать статус своих заявок и список кампаний, в которых участвует.

---

### 👤 Профиль пользователя

Профиль содержит:

* информацию о пользователе;
* персонажей;
* созданные кампании;
* игровые группы;
* историю заявок.

---

### 🤖 Smart Matchmaking

В дальнейшем PartyForge получит рекомендательную систему, которая сможет подбирать наиболее подходящие кампании для игрока.

При подборе могут учитываться:

* предпочитаемый стиль игры;
* опыт игрока;
* любимые классы и роли;
* формат проведения игры;
* расписание;
* интересы;
* история взаимодействия с кампаниями.

DS/ML-компонент планируется реализовать отдельно на **Python** и развивать независимо от основной бизнес-логики приложения.

# 🏗 Архитектура

Основное приложение строится как **модульный монолит**.

```text
                    ┌─────────────────┐
                    │      React      │
                    │   TypeScript    │
                    └────────┬────────┘
                             │
                          REST API
                             │
                    ┌────────▼────────┐
                    │   Spring Boot   │
                    │                 │
                    │ Modular Monolith│
                    └────────┬────────┘
                             │
                    ┌────────▼────────┐
                    │   PostgreSQL    │
                    └─────────────────┘
```

Приложение разделяется на независимые функциональные модули.

Пример:

```text
backend/
├── auth/
├── users/
├── characters/
├── rules/
├── campaigns/
├── applications/
├── matchmaking/
└── common/
```

Каждый модуль отвечает за собственную предметную область.

Такой подход позволяет сохранить простоту монолита на раннем этапе и при этом избежать сильного связывания бизнес-логики.

# 🚀 Запуск проекта

## Требования

Для локального запуска понадобятся:

* Java 25;
* Maven;
* Node.js;
* npm;
* PostgreSQL 18.

---

## 1. Клонирование проекта

```bash
git clone <repository-url>
cd partyforge
```

---

## 2. PostgreSQL

Создайте базу данных:

```sql
CREATE DATABASE partyforge;
```

Настройте подключение backend к PostgreSQL через переменные окружения.

Пример:

```env
DB_URL=jdbc:postgresql://localhost:5432/partyforge
DB_USERNAME=postgres
DB_PASSWORD=password
```

Не добавляйте реальные пароли и секреты в Git.

---

## 3. Backend

```bash
cd backend
./mvnw spring-boot:run
```

После запуска API будет доступен локально через Spring Boot.

---

## 4. Frontend

```bash
cd frontend

npm install
npm run dev
```

После запуска Vite выведет адрес frontend-приложения в терминал.

# 🔐 Роли

В системе предусмотрены следующие роли.

### Guest

Может:

* просматривать публичную информацию;
* искать кампании;
* использовать справочник.

### User

Может:

* создавать персонажей;
* создавать кампании;
* отправлять заявки;
* вступать в игровые группы;
* редактировать свой профиль.

### Administrator

Может:

* модерировать пользователей;
* модерировать объявления;
* управлять игровым контентом.
